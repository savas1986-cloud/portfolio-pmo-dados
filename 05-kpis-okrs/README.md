## Projeto 5 — OKRs e KPIs para Projeto de Dados

**Contexto:** Definição de objetivos e indicadores para o projeto do Painel de Produtividade — empresa
         de tecnologia no setor financeiro regulado
         (TechFinance S.A., contexto fictício)" —
cobrindo desde a fase técnica até a adoção pelos usuários finais.

**O que entrega:** 3 OKRs com Key Results mensuráveis + 5 KPIs
operacionais do projeto + 5 KPIs do painel, fórmula de cálculo, meta, dimensões
de análise e frequência de atualização.

**Por que importa:** Projetos de dados sem métricas de sucesso
definidas não têm critério de encerramento. OKRs mal escritos
geram retrabalho de escopo no meio da execução.

**Habilidades demonstradas:** Framework OKR · Definição de KPIs ·
Governança de métricas · Alinhamento estratégico com negócio
