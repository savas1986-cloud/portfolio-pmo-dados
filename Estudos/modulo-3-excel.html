Aula 1 — Tabelas Dinâmicas Avançadas
📚

Tabela Dinâmica com % e Filtros Interativos

Estrutura montada — SquadID × StatusID com % do Total da Linha
Linhas: SquadID  ·  Colunas: StatusID  ·  Valores: Contagem de DemandaID → % do Total da Linha
Squad Onboarding | 75,00% Concluído | 3,85% Bloqueado Squad Crédito | 73,08% Concluído | 5,77% Bloqueado Squad Segurança | 54,17% Concluído | 12,50% Bloqueado ← alerta Squad Infraestr. | 50,00% Concluído | 8,33% Bloqueado ← alerta
📌 Como aplicar: clique com botão direito em qualquer valor → Mostrar Valores Como → % do Total da Linha.
Slicer de PrioridadeID
Filtro visual clicável que controla a tabela dinâmica. Inserir → Segmentação de Dados → PrioridadeID. Mesmo conceito do slicer no Power BI.
📌 Um slicer pode ser conectado a múltiplas tabelas dinâmicas: clique direito → Conexões de Relatório.
Timeline de DataAbertura
Seletor visual de período por mês, trimestre ou ano. Especificamente para colunas de data. Análise de Tabela Dinâmica → Inserir Linha do Tempo.
📌 Melhor que slicer de data comum — não lista cada dia individualmente. Arraste para selecionar o intervalo desejado.
Por que % do Total da Linha é melhor que Campo Calculado para percentuais
Campos calculados em Pivot Tables operam sobre valores já agregados. Não é possível filtrar "contar só StatusID = 3" dentro da fórmula. Para percentuais baseados em categorias, "Mostrar Valores Como" é o caminho correto — mais simples e produz o mesmo resultado.
📌 Campo Calculado é útil para operações como Receita / Quantidade. Para % de categorias, sempre use "Mostrar Valores Como".
Aula 2 — Power Query no Excel
⚙

Merge de 3 Tabelas via Power Query

💡
Mesma ferramenta, mesma lógica: o Power Query Editor no Excel é idêntico ao do Power BI. As Etapas Aplicadas, os tipos de dado e a operação de Mesclar Consultas funcionam exatamente da mesma forma.
Fluxo do merge
demandas.csv (420 linhas, 10 colunas) + squads.csv (8 linhas) → LEFT JOIN por SquadID + status.csv (5 linhas) → LEFT JOIN por StatusID = Mesclar1 (420 linhas, 12 colunas) com SquadNome e StatusNome resolvidos
📌 Dados → Obter Dados → De Arquivo → De Texto/CSV → Transformar Dados. Sempre importar CSV via Power Query para controlar encoding (UTF-8) e separadores.
Mesclar Consultas — pásso a passo
1. Selecione a consulta demandas
2. Página Inicial → Mesclar Consultas
3. Selecione squads como segunda tabela
4. Coluna de junção: SquadID (nas duas)
5. Tipo: Externa esquerda (LEFT JOIN)
6. Expandir coluna → marcar apenas SquadNome

Aula 3 — PROCX e PROCV
🔗

Cruzamento de Tabelas por Fórmula

💡
PROCX e PROCV = JOIN por fórmula: fazem exatamente o que o JOIN faz no SQL e o Mesclar faz no Power Query. A diferença é que a fórmula calcula linha a linha, em tempo real, sem criar uma nova tabela.
PROCX (Português) = XLOOKUP (Inglês) — Microsoft 365+
PROCX(valor_procurado; matriz_procura; matriz_retorno) -- Aplicado: SquadID → SquadNome =PROCX([@SquadID]; squads!A:A; squads!B:B) -- [@SquadID] = referência estruturada (tabela reconhecida pelo Excel) -- squads!A:A = coluna SquadID na aba squads (onde procurar) -- squads!B:B = coluna SquadNome na aba squads (o que retornar)
📌 No Excel em português: XLOOKUP = PROCX. Quando o Excel reconhece a tabela como estruturada, substitui C2 por [@NomeColuna] automaticamente — mais robusto.
PROCV — versão clássica (todas as versões do Excel)
PROCV(valor_procurado; tabela_matriz; núm_índice_col; 0) -- Aplicado: StatusID → StatusNome =PROCV([@StatusID]; status!$A:$B; 2; 0) -- status!$A:$B = procura nas colunas A e B da aba status -- 2 = retorna a 2ª coluna (StatusNome) -- 0 = correspondência EXATA (nunca omitir)
⚠ O 0 no último argumento é obrigatório. Sem ele, o Excel usa correspondência aproximada e pode retornar valores errados se a tabela não estiver ordenada.

Aula 4 — Macro Básica
⚡

Automatizando Formatação com Ctrl+Shift+F

💡
O que é uma macro: uma sequência de ações gravada e executada com um atalho. Tudo que você faria manualmente toda vez que receber uma planilha bruta — formatar cabeçalho, ajustar colunas, congelar linha — vira um clique.
Macro criada: FormatarRelatorio (Ctrl+Shift+F)
Ações gravadas em ordem:
1. Selecionar Linha 1 (cabeçalhos) 2. Aplicar Negrito (Ctrl+N) 3. Cor de fundo: Azul escuro (#1E3A8A) 4. Cor de fonte: Branco 5. Selecionar todas as colunas (A até L) 6. Formatar → Autoajustar Largura da Coluna 7. Exibição → Congelar Painéis → Congelar Linha Superior 8. Clicar em A1
📌 Resultado: cabeçalho azul escuro com fonte branca, colunas ajustadas ao conteúdo, linha 1 congelada. Aplicado em 1 segundo com Ctrl+Shift+F.
Como gravar uma macro
1. Aba Desenvolvedor → Gravar Macro
2. Nome: sem espaços
3. Atalho: Ctrl+Shift+letra
4. Armazenar em: Esta pasta de trabalho
5. Execute as ações
6. Parar Gravação
📌 Habilitar Desenvolvedor: Arquivo → Opções → Personalizar Faixa de Opções → marcar Desenvolvedor.
⚠ Salvar como .xlsm
Macros não são salvas em arquivos .xlsx comuns. Sempre salvar como:
Arquivo → Salvar Como → Pasta de Trabalho Habilitada para Macro do Excel (*.xlsm)
Se salvar como .xlsx, as macros são perdidas sem aviso. O Excel alerta sobre isso ao fechar.

Insights do Módulo 3

🔗
PROCX, JOIN, Mesclar Consultas — mesma lógica, três ferramentas
As três operacionalizam o mesmo conceito: pegar um ID numa tabela e trazer o nome correspondente de outra. No SQL é JOIN, no Power Query é Mesclar, no Excel por fórmula é PROCX ou PROCV. Quem entende a lógica aplica em qualquer ferramenta — quem decora a sintaxe fica preso a uma só.
⚠
O 0 no PROCV nunca pode ser omitido
Sem o quarto argumento 0, o Excel usa correspondência aproximada. Se a tabela de referência não estiver ordenada, o resultado é errado sem nenhum erro de sintaxe. O banco não reclama — o número simplesmente está errado. É o mesmo tipo de bug silencioso do GROUP BY por nome em vez de por ID no SQL.
🔴
Encoding de CSV é detalhe que quebra tudo
Abrir um CSV com duplo clique usa o encoding padrão do sistema, que no Windows geralmente é ANSI — e acentos viram caracteres inválidos. Sempre importar via Dados → Obter Dados → De Arquivo, selecionando UTF-8 explicitamente. É o mesmo problema que causou 17% de erros nas datas no Power BI — o dado estava certo, a leitura estava errada.
🎨
% do Total da Linha é mais poderoso que Campo Calculado para categorias
Campo Calculado é útil para operações aritméticas simples entre medidas (ex: margem = receita / custo). Para percentuais baseados em subcategorias (% de concluído por squad), "Mostrar Valores Como → % do Total da Linha" é o caminho correto, mais simples e sem limitações de sintaxe.
⚡
Macro é o primeiro passo de automação — e o mais fácil de justificar
Uma macro que formata uma planilha em 1 segundo em vez de 5 minutos poupa 40 horas por ano se feita toda semana. Isso é o argumento concreto para apresentar automação para um gestor que nunca pediu. PMO de Dados não espera ser solicitado — identifica o desperdício e entrega a solução.
🎯
Squad Segurança com 12,5% bloqueado aparece em todas as ferramentas
No SQL (GROUP BY), no Power BI (gráfico de barras + DAX), e agora no Excel (tabela dinâmica com %). O mesmo dado, três leituras diferentes, mesma conclusão. Quando um insight se confirma em múltiplas ferramentas, é dado — não artifact o da ferramenta.
