# Excel Avançado — Análise de Demandas

Análise dos dados do Painel de Produtividade usando Excel avançado.

## O que foi feito
- Tabela Dinâmica com % por linha e slicers interativos
- Timeline de DataAbertura por trimestre
- Power Query — merge de 3 tabelas (demandas + squads + status)
- PROCX e PROCV para resolver IDs em nomes reais
- Macro para formatação automática do relatório (Ctrl+Shift+F)

## Arquivo
`painel-produtividade-excel.xlsm` — pasta de trabalho com macro habilitada
